NusaStat — a national statistics site for Indonesia, built as plain static files with no network requests. Seven linked pages (Home, Economy, Demography, Provinces, Health & Education, Compare, Sources) with real figures from BPS, the World Bank, SSGI, and APJII, each figure labelled with its source and year. Pure-SVG charts (GDP growth, inflation, poverty, population, sector mix, religion), a province explorer with search, sorting and detail panels, a year-range and indicator switcher, and a country-comparison tool — all working on desktop and phone.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
